# ADR-009 — 静音保持优先于 `--gap` 硬垫

- 状态：接受
- 日期：2026-07-26
- 关联：Spec 15；issue #001

## 背景
issue #001 报告两类现象：cue 之间无空隙、部分 cue 提前出现。候选修复：
- **(A) 词级边界 + stable-ts 保静音**：从源头保留真实停顿（根治"提前"、暴露被吞的真实静音）。
- **(B) `--gap` 硬垫**：相邻 cue 间强制留最小间隔，人为制造空隙。
- **(C) 固定偏移**：给所有 cue 加固定时间偏移（否决，会系统性破坏对齐）。

## 决策
**(A) 为主，`--gap` (B) 仅兜底。**

理由：
- 真实停顿是**声学事实**。正确做法是保留它，而非人为制造一个"看起来有空隙"的伪间隔——后者在真实有停顿处会叠加成过大间隙，在真实无停顿处又画蛇添足。
- 实证（明星模仿秀.mp4）：视频里有 1.2s / 1.0s / 1.4s 等真实静音，但 faster-whisper 把它们吞进长段内部、相邻段墙到墙零间隙。这是"被吞"，不是"音频密"，因此应从源头（词级时间戳 + `split_by_gap`）修复，而非 `--gap` 糊弄。
- `--gap` 的合法语义只剩"钳制裁掉尾随静音、不让相邻 cue 重叠"，**绝不制造间隙**。

## 重申不变量
**时间戳是声学事实，绝不重算。** 任何"收紧/钳制"只取声学事实（词边界）或裁尾随静音，绝不重算语义边界——否则破坏 golden 字节级根基（违反 `AGENTS.md` Hard rule 1）。

## 后果
- `generate.py` 改用首词/末词边界（需 Spec 12 的 words）。
- `generate` / `run` 新增 `--gap`（默认 0.2s），仅兜底钳制。
- 退化路径：无 `words` 时不钳制或回退段级时间。
